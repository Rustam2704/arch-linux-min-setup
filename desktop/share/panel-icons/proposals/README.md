# Варианты значков CPU / RAM / SWAP

Три стиля на выбор, каждый — три SVG 36×36 (размер картинок панели):

- `battery-*` — как у батареи: контур и цветной уровень внутри (зелёный/жёлтый/красный по загрузке);
- `diablo-*` — пиксель-арт в золоте и коричневом игры, с красным камнем;
- `segment-*` — сегменты как у семисегментных часов, светло-голубые.

`preview.png` — все девять на чёрном в 3×. Понравившийся стиль скажите — переведу `panel-sys` на него
(значок будет перерисовываться под уровень, как батарея).
