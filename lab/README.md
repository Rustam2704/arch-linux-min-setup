# lab — журнал изменений системы

Каждое изменение системы записывается в `journal.tsv` (по одной строке на действие:
время, эксперимент, действие, путь, копия). Цель — не страховка, а **точный итоговый дифф**:
видеть всё, что поменялось в системе, и иметь возможность откатить любой эксперимент.

Обычный путь — `make apply EXP=NN-name` (см. [README.md](../README.md)): дерево `desktop/`
устанавливается через `lab write`, так что журнал остаётся полным. Прямо `lab/lab` нужен для
того, что деревом не описывается: пакеты, настройки xfconf, удаление файлов.

## Команды
```bash
lab/lab write  <эксп> <путь>  < файл     # записать файл (старый уходит в backups/)
lab/lab remove <эксп> <путь>             # удалить файл (копия в backups/, откат вернёт)
lab/lab pkg    <эксп> <пакет>...         # установить пакеты, записать новые
lab/lab undo   <эксп> '<команда>'        # команда отката для всего остального (xfconf и т. п.)
lab/lab status                           # что применено, по экспериментам
lab/lab rollback <эксп> | all            # откатить (rollback.py: с проверкой конфликтов)
```

Откат отказывается восстанавливать файл, который позже менял другой эксперимент
(иначе затёр бы более поздние правки) — тогда откатывать надо начиная с последнего.
Неудавшийся шаг остаётся в журнале.

`backups/` в git не входит (`.gitignore`): это копии установленных файлов до каждой правки,
нужные только для отката на этой машине. История содержимого и так есть в git.

Страховка последнего рубежа — снапшот Timeshift `before-lab-experiments` (`sudo timeshift --list`).
