# Требования (список, чтобы не забывать)

Собрано из разговоров 2026-09-17. Это список «что должно быть», а не план работ.
План и статус — в `PLAN*.md` и `CHANGELOG.md`.

## Общие принципы
1. **Сначала ищем готовое решение**, своё пишем только если готового нет или оно хуже.
   С нуля строить — последний вариант.
2. **Отполированность важнее эффектов.** Анимации не нужны. Нужны ровная разметка,
   одинаковые размеры значков и предсказуемое поведение.
3. **Привычки из Windows** там, где они удобнее.
4. **Ресурсы:** 8 ГБ ОЗУ и встройка Haswell. Перерисовка панели несколько раз в секунду —
   нормально. Постоянные 60-кадровые анимации — нет.
5. **Любой наш интерфейс сохраняет настройки сразу**, без кнопки «Save».
6. **Весь интерфейс — на английском** (подписи, подсказки, OSD, меню, календарь),
   даже если разговор идёт по-русски.
   (В прошлом расширении `firefox-memory-guard` настройки терялись, если не успел нажать Save.)

## Рабочий стол
- Все кнопки в одной верхней панели; нижнюю убрать.
- Кнопки не дублируют друг друга; лишние (показать рабочий стол, appfinder, второй терминал) убрать.
- Клик по значку программы: переключиться на её окно; новое окно — только с модификатором
  или средней кнопкой.
- Клик по значку в панели задач переключает на рабочую область с этим окном.
- Рабочие области не исчезают и не теряют имена, когда из них убрали окна.
- Файловый менеджер открывается сразу в папке, без шага «Open Folder».
- Регулятор громкости виден поверх полноэкранного видео, не дёргается,
  непрозрачность 90%. Изменение громкости в режиме mute снимает mute.
- Небольшая быстрая всплывашка при смене раскладки — рядом с индикатором раскладки,
  не по центру экрана.
- Значок Telegram показывает число непрочитанных личных сообщений
  (без архива и чатов без звука).
- Батарея при полном заряде показывает `100%`, а не 97% (аккумулятор изношен,
  контроллер заканчивает заряд на 97.8%). Слово «заряжена» не нужно.
- Данные о процессоре, памяти и сети должны быть правдивыми и читаемыми.
  По сети — не объём трафика, а качество связи: мгновенное и медианное значение,
  чтобы было видно, когда интернет тупит. Медиана — за последние 10 с, отдельно до роутера
  и до интернета. Тест скорости — только из меню индикатора, никогда случайно.
- Погода: обновляется сама, не ломается без интернета, показывает последнее значение.
- Часы: небесно-голубые семисегментные цифры, цвет с образца — **#48daf9**
  (образец: настенные часы, ссылка в переписке).
- Несколько экранов: отдельное переключение рабочих областей на каждом экране.

- Подписи раскладок: EN / RU / UA. `Alt+Shift` — EN ⇄ RU (из UA — в EN),
  `Ctrl+Shift` — сразу UA. Срабатывает при отпускании, не мешая `Ctrl+Shift+V` и т. п.
- Скриншот — `Super+Shift+S` (как в Windows, чтобы не путаться в RustDesk).
  Горячие клавиши по возможности совпадают с Windows.
- Текстовые файлы (включая `*.md`) по умолчанию открываются в Sublime Text.
- Окна как в Windows: у всех окон шапка с кнопками «свернуть / на весь экран / закрыть»
  (цветные круги как у Apple, но справа, одинаковые во всех программах);
  растягивание за край мышью без клавиш; правый клик по шапке — плитка ⇄ плавающее;
  перетаскивание правой кнопкой за шапку — перемещение; к верхнему краю — на весь экран,
  к левому/правому — половина экрана плиткой (с голубым превью, без анимации).
- «На весь экран» не закрывает верхнюю панель; выход (кнопка, перетаскивание, свайп
  вниз) возвращает окно в прежнее состояние.
- Окно можно перетащить на кнопку рабочей области в панели.
- У каждого экрана свои рабочие области, переключение на каждом отдельно
  (как «Switch desktop independently for each screen» в Plasma 6.7).
  Поведение при отключении экрана — сверить с Plasma.
- Программы открываются на закреплённых за ними рабочих областях (один конфиг-файл).
- Меню под «яблоком»: переключатель автозапуска избранных программ (действует на все
  старты, пока не выключишь), кнопка «запустить все сейчас», список иконок
  с включением/исключением, кнопка «+» для добавления программы.

## Звук
- Шумоподавление микрофона для звонков из кафе, с понятным устройством
  (не «чёрный ящик» Zoom). Изоляция голоса по образцу: сначала без обучения
  («шлюз по голосу»), полная модель по статье — отдельным проектом.

## Firefox и память
- Общая цель: Firefox не больше ~4 ГБ, остальное уходит на SSD **без перезагрузки страниц**
  (своп, а не discard).
- Выгрузка в своп — **заранее, в фоне**: «комфортный» уровень ~2 ГБ, старые вкладки
  уходят первыми, чтобы новая вкладка не ждала 10 секунд.
- Потолок (сейчас 4 ГБ) меняет только пользователь; автоматически не поднимать.
- Своп на SSD (zram сейчас не справляется), лимит через cgroup.
- Переключатель и лимит — в расширении Firefox: включение и выключение без сохранения,
  лимит и частота выгрузки задаются на месте.
- YouTube — главный потребитель: ограничить память на превью, по возможности
  не декодировать видео в неактивном окне, звук при этом сохранить.
- Картинки: по умолчанию лёгкие, полное качество — по наведению.
- Расширения для конкретных сайтов должны работать только на своих сайтах.

## Календарь
- Название — **light-year** (везде).
- Лёгкое отдельное окно без браузерного движка: **~50 МБ, максимум 100**; из браузерных функций нужна только
  кнопка «Обновить». Своя иконка, не смешивается с окнами Firefox.
- Свой мини-календарь вместо веб-версии Google (500 МБ на календарь недопустимо).
- Нужно только: вид «месяц», переход между месяцами, создание, редактирование,
  перенос событий перетаскиванием.
- Виды «день» и «неделя» не нужны.
- Из интеграций нужен только Zoom: создание встречи и обновление времени при переносе.

## Решено
- Оболочка: **XFCE + i3**, самый лёгкий вариант. Функции Plasma и Windows пишем сами
  (см. `PLAN3.md`).
- Демонстрацию экрана в Zoom пока не трогаем.
