# dock-rtl — GTK-модуль: док справа налево

docklike добавляет новую группу окон в конец своего бокса; в боксе «справа налево» конец —
это левый край, поэтому закреплённые остаются справа (последний в списке `pinned` — самый
правый), а новые программы появляются слева. Модуль грузится во все GTK-программы сессии
через `GTK_MODULES` (`xfce-i3-session`), но действует только в процессе-обёртке панели с
`libdocklike.so` — смотрит на свою командную строку.

Сборка: `make` в этой папке (gcc, gtk3) → `desktop/share/sky-desktop/libdock-rtl.so`.
Побочность: в процессе дока зеркалятся и его меню/превью. Откат: убрать `GTK_MODULES` из
сессии и файл из дерева.
