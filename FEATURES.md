# Что здесь реализовано

Полный список возможностей рабочего стола, собранных в этом проекте на whitebook
(MacBookPro11,1, Arch Linux, Xorg). Как это устроено — [ARCHITECTURE.md](ARCHITECTURE.md),
история — [CHANGELOG.md](CHANGELOG.md), как поднять с нуля — [BOOTSTRAP.md](BOOTSTRAP.md).

## Сессия и система

- Своя сессия **«Xfce + i3»**: инфраструктура Xfce (xfsettingsd, панель, power manager, Thunar,
  notifyd) с оконным менеджером i3, без xfce4-session. LightDM входит в неё автоматически, без
  выбора сессии; systemd-boot без задержки.
- Всё установленное объявлено в дереве `desktop/` и ставится одной командой (`make apply`),
  каждое изменение системы — в журнале `lab/` с откатом по эксперименту; свойства xfconf
  (панель, xsettings, раскладки, power manager, Thunar) тоже объявлены и ставятся живьём.
- Единая система стиля: `theme.json` с токенами цветов и шрифтов, которые подставляются во все
  конфиги и скрипты (`@COLOUR_…@`, `@FONT@`, `@PANEL_FONT@`); `make check` не пропускает цвет
  литералом и личные пути. Тема GTK Sky-Dark и свой набор иконок Sky-Dark-Icons.
- HiDPI 1,5× (144 dpi) везде: Xft, GTK, панель 66 px, крупные элементы управления.
- Тесты: `make test` — unit-тесты календаря и аккордов раскладки, GTK-smoke на Xvfb.
- Для MacBook: обход 30-секундной задержки прошивки, тишина при включении, Wi-Fi BCM4360,
  Fn ⇄ Ctrl, вентилятор (mbpfan), камера (facetimehd).

## Окна как в Windows (deskd)

- Кнопки в шапке каждого окна: свернуть / развернуть / закрыть, цветные, символы появляются
  при наведении.
- Перетаскивание за шапку любой кнопкой мыши одним движком: к верху — развернуть, к левому
  или правому краю — половина экрана, на цифру области в панели — переезд туда (цели
  подсвечиваются красными рамками). Растягивание за промежутки между плитками и за края
  плавающих окон; Super + правая кнопка — растягивание из любой точки окна.
- «Развернуть» — плавающее окно на всю рабочую область под панелью с точным возвратом на
  прежнее место в плитках (место держит заглушка). Двойной клик по шапке, Super+F, жест.
- Сворачивание в scratchpad и возврат (Super+−, Super+Shift+−), Alt+Tab / Alt+Shift+Tab по
  окнам области, стрелки Super+← ↑ → ↓ для фокуса.
- Правильный порядок окон: активное плавающее сверху, диалоги всегда над своим владельцем.
- Фокус по клику, как в Windows; наведение мыши фокус не меняет.
- Новые окна программы появляются рядом с первым; всплывающие (диалоги, уведомления,
  настройки Zoom, Flameshot, Pavucontrol и т. п.) плавают сами.
- **Рабочие области у каждого экрана свои** («1…6» на каждом), при отключении экрана его области
  переходят ноутбуку, при подключении возвращаются; раскладка экранов помнится (autorandr);
  панель на втором экране создаётся автоматически.
- Режим `passthrough` для RustDesk: все клавиши и мышь уходят удалённой машине, окно при этом
  всё равно переносится мышью за шапку и горячими клавишами.
- Автоматика: окно «Update - Sublime Text» закрывается при появлении; Telegram не показывается в
  доке (у него свой индикатор); панель аннотаций и самовидео Zoom плавают без фокуса.
- Меню за кнопкой-яблоком: избранные программы с фиксированными областями, «запустить
  избранное», настройка сохраняется сразу.

## Панель (Xfce, одна строка сверху)

- **Док** (docklike) прижат к полосе областей и растёт влево; закреплённые справа, новые
  программы у левого края (GTK-модуль `dock-rtl`); Ctrl/Shift+клик открывает новое окно.
- **Полоса областей**: цифры 1–6 в шрифте Diablo, активная чёрная под **горящим пламенем и двумя
  вращающимися пентаграммами из Diablo I** (кадры игры, 60 мс на кадр, рисует sky-stars без
  участия композитора); занятые области светлее, «urgent» — акцентом; клик переключает,
  перетаскивание окна на цифру переносит его.
- Стандартный зазор между значками 15 px; ни один индикатор не сдвигает соседей при смене
  показания (табличные цифры, невидимые нули, замер ширины Pango).
- Индикаторы (все свои, genmon): Telegram с числом непрочитанных и кликом-переключателем ·
  Wi-Fi веер с дБм · пинг «сейчас · медиана» и значок задержки · CPU / RAM / SWAP (своп в одну
  цифру, красным от 10 ГБ) · погода Open-Meteo с иконкой и температурой · батарея с цветным
  уровнем, молнией зарядки и здоровьем в подсказке · звук: динамик с тремя дугами, слот под
  микрофон записи · раскладка EN/RU/UA в цветах флагов · часы в семисегментном шрифте с
  мигающим двоеточием · кнопка выключения.
- Меню по клику: Wi-Fi (сети с уровнем, подключение с паролем, «Refresh», nmtui, редактор
  соединений, выключатель радио — открывается мгновенно из тёплого процесса), сеть (числа
  пинга, тест скорости через Cloudflare), звук (длинные ползунки выхода и входа, Mute,
  переключатель звуков клавиш, микшер), календарь под часами, меню питания, меню батареи с режимами питания.
- Тёмная вуаль над панелью с «дыркой» под курсором — единая подсветка наведения для всех
  плагинов; над полноэкранным окном и во время демонстрации экрана Zoom слои прячутся.
- Тултипы панели не появляются поверх открытых меню.
- Колесо над динамиком — громкость, средняя кнопка — mute.
- **Меню батареи** (клик по батарее): заряд и здоровье, режим питания — Automatic / Performance /
  Balanced / Power saver (профили TLP; экономия: без турбо, потолок CPU 60 %, глубокий сон PCIe),
  выбор помнится между сессиями.

## OSD и клавиатура

- OSD громкости и яркости (в углу) и **попап раскладки по центру экрана** в шрифте Diablo.
- Переключение раскладок как в Windows: **Alt+Shift** EN ⇄ RU, **Ctrl+Shift** → UA, по отпусканию,
  без помех сочетаниям вроде Ctrl+Shift+V; устойчиво к быстрому набору и потерянным
  отпусканиям.
- **Звуки клавиш из Diablo**: Enter — «принять», стрелки — «переход по меню», без задержки и
  без пропусков при быстром нажатии, один общий плеер, выключатель в меню звука.
- Все горячие клавиши работают в любой раскладке.
- Медиаклавиши: громкость, mute, микрофон, яркость экрана и клавиатуры.
- Скриншоты как в Windows: Print — экран, Super+Shift+S — область, в буфер и в файл.
- Super+/ — шпаргалка по клавишам i3 с поиском; Ctrl+Shift+Esc — btop.
- rofi: запуск (Super+D), команда (Super+R), окна (Super+Tab), одна копия за раз.

## Жесты тачпада

- 3 пальца влево/вправо — соседняя область; вверх — переключатель окон; вниз — запуск.
- 4 пальца вверх — развернуть, вниз — вернуть.
- Плагин Qt `scroll-phases` возвращает физические фазы прокрутки тачпада в Qt-программах.

## Терминал kitty

- Ctrl+C / Ctrl+V на любой раскладке, Ctrl+клик по пути открывает файл или папку (включая
  `файл:строка` и пути, разбитые TUI на две строки), средняя кнопка — меню пути,
  Ctrl+Shift+O — открыть выделенное, Shift+клик расширяет выделение.
- `sky-edit` — родной GTK-редактор с автосохранением для внешнего редактора CLI-инструментов.

## Файлы (Thunar)

- **Ctrl+V с картинкой в буфере** сохраняет её в открытую папку файлом `ГГГГ-ММ-ДД ЧЧ-ММ-СС.png`,
  как в Проводнике Windows, на любой раскладке; файлы вставляются как раньше.
- Полный путь в заголовке окна.

## Фон и эффекты

- **Фон-звёзды**: чёрный экран с медленно мерцающими звёздами, дешёвый как обои (просчитанный
  цикл, рисуется только там, где нет окон, спит при закрытом экране).
- Диабло-материалы: шрифт панели `Diablo`, собранный из спрайт-листа игры пиксель в пиксель
  (без швов сглаживания), огонь логотипа и пентаграммы меню, звуки меню.
- Композитор xcompmgr: тени и лёгкое затухание, без прозрачности окон и размытия. Выбран замером
  (`tools/compositor-bench`): под picom перерисовка окна браузера стоила в 2,5–3 раза дороже.

## Сеть

- `netqd`: постоянный пинг роутера и 1.1.1.1, медиана и потери за 10 с, вердикт «медленно:
  Wi-Fi / провайдер», уровень Wi-Fi без сканирования эфира; nm-applet не нужен.
- Меню Wi-Fi сканирует только по клику и только когда кэш NetworkManager почти пуст.

## Календарь light-year (Super+C)

- Родной GTK-календарь без браузера: месяц, события дня с «+N more», создание и правка событий,
  повторения (RRULE), синхронизация с Google Calendar, встречи Zoom (Server-to-Server).

## Firefox и браузер

- `firefox-mem` — потолок памяти живьём; `firefox-limited` — запуск с мягким лимитом памяти.
- Пользовательские скрипты: светлые превью YouTube, звук YouTube в скрытой вкладке, светлые
  картинки при наведении; фильтр uBlock для превью.

## Звук

- Свой индикатор и меню звука (см. панель), состояние из `pactl subscribe` без опроса,
  красный микрофон рядом с динамиком, пока что-то пишет звук.
- Эхоподавление для звонков по переключателю в меню динамика (WebRTC AEC PipeWire, устройства по
  умолчанию для всех программ, пока включено).

## Zoom

- Камера без HD, встречи без видео по умолчанию.
- Индикатор и правила: панель аннотаций и самовидео плавают без фокуса; во время демонстрации
  экрана композитор не выключается (иначе чёрный экран), кадр меняется целиком (без разрывов у
  зрителя), Zoom показывает свои окна зрителю без штриховки.

## Инструменты проекта

- `make check | status | diff | apply | test | packages | rollback`, журнал `lab/` (write, remove,
  pkg, undo, rollback, prune), объявленные xfconf-каналы, токены `@HOME@`/`@USER@`/`@PROJECT@`.
- `i3-peek` (в `~/ai/claude/tools`): посмотреть окно на другой области, не мешая пользователю.
- Генераторы: `diablo-font.py` (шрифт из PCX), `fire-digits.py` (листы огня под цифры панели),
  `make-telegram-icons.py`, сборка `dock-rtl` и `qt-scroll-phases`.
