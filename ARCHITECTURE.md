# Как устроен рабочий стол

## Сессия

`/usr/local/bin/xfce-i3-session` (в дереве: `desktop/system/…`) запускает по порядку:
`xrdb ~/.Xresources` (HiDPI) → `xsetroot` чёрный → `xfsettingsd` (тема, шрифты, раскладки) →
`xfce4-power-manager` → `xfce4-panel` → `Thunar --daemon` → `touchegg` (клиент) → `picom` →
`dex ~/.config/autostart` → `exec i3`. Без `xfce4-session`: он спорил бы с i3 за размещение окон.
LightDM автологинит в эту сессию (`/usr/share/xsessions/xfce-i3.desktop`).

Службы `systemctl --user`: `deskd` и `osd` запускает i3 (им нужен X; служба, стартующая до X,
падает и systemd сдаётся), `netqd`, `firefox-memd`, `sky-stars` — `graphical-session.target`.

| Служба | Что делает | Память | CPU в простое |
|---|---|---|---|
| `deskd` | окна как в Windows, панели, области на каждом экране | ~35 МиБ PSS | ≈0 (события i3) |
| `osd` | OSD громкости/яркости/раскладки, переключатель раскладок | ~30 МиБ | ≈0 |
| `netqd` | ping роутера и 1.1.1.1 раз в секунду → `$XDG_RUNTIME_DIR/netq*.txt` | ~8 МиБ | ~0.03 % |
| `firefox-memd` | фоновая выгрузка памяти Firefox в своп до 2 ГБ | ~5 МиБ | ~0.4 % (работа ядра) |
| `sky-stars` | фон-звёзды | 23 МБ RSS | 0 при закрытом экране, ≤0.6 % при открытом |
| `light-year` | календарь, только пока открыт (Super+C) | ~42 МиБ | — |

## Общая библиотека `~/.local/share/sky-desktop/`

`theme.json` (стиль, см. README), `sky_theme.py` (`THEME`, `css()`, `rgb()`, `icon()`),
`i3ipc.py` (клиент i3 IPC: `I3` для команд и запросов; `subscribe()`/`decode()` для сырого
сокета в цикле `select()`; `Subscription` для GLib — GLib импортируется лениво).
Скрипты добавляют этот каталог в `sys.path`. Панельные скрипты GTK не импортируют.

## deskd (`~/.local/share/deskd/deskd.py`, `panels.py`)

Python + python-xlib + GTK, живёт на событиях i3 IPC (`window`, `workspace`, `output`,
`binding`, `tick`) и на X-событиях своих окон. События `window::title`/`urgent` пропускает
(ничего не двигают, а спиннер в заголовке терминала шлёт их каждые 100 мс).

- **Шапки**: i3 рисует заголовок, deskd кладёт поверх него три маленьких окна-кнопки
  (свернуть / развернуть / закрыть — цвета `warning`/`success`/`danger`). Клик, двойной клик,
  правый клик (плитка ⇄ плавающее), перетаскивание обеими кнопками — один движок:
  к верху = развернуть, к левому/правому краю = половина экрана, на цифру области в панели =
  переезд туда. Растягивание за промежутки между окнами и за края плавающих.
- **Развернуть** = плавающее окно на всю рабочую область под панелью. Возврат точный:
  в плитках место держит пустой контейнер-заглушка (`remember(placeholder=True)`), помеченный
  меткой; в конце `maximize()` фокус явно отдаётся окну (i3 фокусирует новый контейнер).
- **Порядок окон**: i3 держит плитки и плавающие в разных стеках; `raise_focused()` поднимает
  рамку активного окна над остальными рамками области и следит, чтобы любой диалог
  (`WM_TRANSIENT_FOR`) был над своим владельцем — i3 при каждой смене фокуса заново выставляет
  свой порядок (активное плавающее сверху), поэтому проверяются все пары области, и
  `ConfigureWindow` шлётся только когда порядок реально неверен (иначе петля
  `ConfigureNotify → refresh`).
- **Панель**: deskd держит над ней тёмную вуаль с «дыркой» под курсором (genmon никогда не
  получает `:hover`), пентаграмму над активной областью, пишет полосу областей
  (`$XDG_RUNTIME_DIR/deskd-workspaces-*.txt`) и меряет её ширину тем же шрифтом с `tnum=1`,
  что и панель — от этого зависят зоны клика и цели перетаскивания. Над полноэкранным окном
  ни вуали, ни пентаграммы. `panels.py` создаёт панель для второго экрана.
- **Огонь и вращающиеся пентаграммы у активной цифры** рисует `sky-stars` (класс окон
  `sky-marks`): deskd лишь пишет, где цифра (`$XDG_RUNTIME_DIR/deskd-mark.json`), потому что сам
  на переключении области занят до 0,3 с и замораживал бы анимацию. Кадры — из
  `external-assets/fire-digits/` (пикс-мапы на X-сервере, `CopyArea` раз в 60 мс). deskd ставит эти
  окна под вуаль по тику `deskd overlays`; нарисованная пентаграмма выключена (`STAR_MARK`).
- **Тултипы панели** не показываются, пока открыто наше всплывающее окно (меню Wi-Fi, питания,
  календарь): deskd видит появление окна типа `TOOLTIP` и прячет его.
- **Области у каждого экрана свои** (`1:eDP-1`, `1:HDMI-2` → в панели «1…5»); отключённый
  экран отдаёт области ноутбуку, подключённый забирает обратно; раскладку помнит autorandr.
- RustDesk в фокусе → режим i3 `passthrough`. Новые окна программы — рядом с первым.
  `deskd-ctl` шлёт команды через i3 `tick` (жесты touchegg, Super+F).

## Панель Xfce (одна строка сверху, 66 px, 144 dpi)

Плагины по id: `1` меню-яблоко · `57` docklike · `45` области · `52 53 54` линии ·
`50 51` растяжки · `6` трей (пустой) · `58 59` отступы · `40` Telegram · `56` отступ ·
`60` Wi-Fi · `41` пинг · `42` CPU/RAM/SWAP · `43` погода · `44` батарея · `62` звук (`panel-audio`; меню
`audio-menu`; колесо и средняя кнопка — слой deskd; состояние пишет osd-daemon из `pactl subscribe`) ·
`55` раскладка · `8` часы · `21` выключение. Индикаторы — genmon-скрипты `desktop/bin/panel-*`
(протокол `<img>`/`<txt>`/`<css>`/`<txtclick>`), значения читают файлы `netqd` и deskd.

Что легко сломать:
- **Шрифт genmon читается только при старте плагина**: менять через `xfce4-panel -q`, правку
  xfconf, запуск. **Панель запускать только через i3** (`i3-msg 'exec --no-startup-id xfce4-panel'`),
  иначе она унаследует окружение вызвавшего процесса.
- `<img>` у genmon — отдельным тегом, не внутри `<txt>`. Картинка показывается ~32 px по
  высоте — рисунок должен занимать весь холст. Свои `*-symbolic` GTK перекрашивает — цвет
  держится только inline-стилем с `!important` у каждой фигуры.
- `Ctrl+клик` по панели перехватывает Xfce (меню элемента) → «новое окно» = `Shift+клик`.
- Раскладка панели — состояние xfconf (`~/.config/xfce4/xfconf/xfce-perchannel-xml/xfce4-panel.xml`),
  деревом не описана; изменения свойств — через `lab/lab undo` с командой отката.

## Фон `sky-stars`

Override-redirect окно типа `DESKTOP` в самом низу стека X (i3 такие окна не трогает: ни рамки,
ни области), python-xlib без GTK. 30-секундный цикл мерцания просчитан при старте (120 кадров
по 250 мс, 12 ступеней яркости, периоды 3,75–7,5 с — делители 30 с, стык бесшовный); кадр —
до 25 запросов `PolyFillRectangle` с заранее упакованными прямоугольниками. Перекрытие
считается по дереву i3: форма окна (XShape) = незакрытая часть экрана, под окнами не
рисуется, при полном перекрытии процесс спит до события i3.

Почему не корневое окно: под picom корневое окно не видно вообще — композитор показывает
свою копию root pixmap и перечитывает её только при смене `_XROOTPMAP_ID`, то есть каждый
кадр стоил бы полноэкранной перекомпозиции. У окна есть точный damage.

## OSD и раскладки (`osd-daemon`, `osd`)

Окно поверх всего, включая полноэкранное; фиксированная ширина, непрозрачность 90 %.
Клавиши громкости/яркости из i3 вызывают `osd …`, mute снимается перед изменением.
Переключатель раскладок слушает XRecord: `Alt+Shift` EN ⇄ RU (из UA → EN), `Ctrl+Shift` → UA,
срабатывает при отпускании и только если между нажатием и отпусканием не было другой клавиши
(поэтому `Ctrl+Shift+V` в kitty работает). Индикатор — `panel-layout` (цвета `layouts` темы).

## Сеть

`netqd` держит два постоянных `ping` (роутер и 1.1.1.1), пишет задержку и медиану за 10 с,
уровень Wi-Fi в дБм (`iw`, без сканирования эфира: `nmcli … --rescan no`). `panel-wifi` (веер)
и `panel-net` (пинг) — два плагина; `net-menu --wifi` (сети, пароль, nmtui, редактор соединений)
и `--info`; тест скорости только из меню. `nm-applet` не запускается.

## Календарь `light-year` (`~/.local/share/light-year/`)

GTK3 без браузера: `app.py` окно, `widgets.py` (RecurrencePicker, DayEvents с `+N more`,
TimeField, MiniCalendar), `recurrence.py` (RRULE ⇄ режимы), `api.py` (Google Calendar API,
Zoom Server-to-Server OAuth). Месяц из шести недель (сетка не прыгает), оттенки колонок 2 %,
перенос перетаскиванием (сохраняется сразу), форма события пишет **только по Save**
(Cancel/Esc отбрасывают черновик), повторяющиеся события с охватом this / following / all,
встречи Zoom создаются/переносятся/удаляются вместе с событием. Ключи — `~/.config/light-year/`
(права 600, вне репозитория). Вход в Google открывает `127.0.0.1:8412` на несколько секунд.

Подключения: Google — проект `calendar-508922`, OAuth-клиент Desktop `light-year-web`, статус
**In production** (в Testing доступ отзывался бы раз в 7 дней), только `calendar.events`;
Zoom — приложение Server-to-Server OAuth с правами `meeting:write/update/delete:meeting:admin`.

## Терминал, жесты, клавиши

- **kitty**: выделение → буфер; `Ctrl+C`/`Ctrl+V` на любой раскладке (`--allow-fallback=shifted,ascii`);
  `Ctrl+клик` по пути открывает его (`open-click.py` + `open-path`, в том числе путь, разбитый
  TUI на две строки), средняя кнопка — меню пути, `Ctrl+Shift+O` — открыть выделенное,
  `Shift+клик` расширяет выделение, правый клик глушится. `sky-edit` — внешний редактор GTK
  для Codex (`VISUAL` задаётся только в обёртке `codex()` в `~/.bashrc`).
- **touchegg**: 3 пальца ←/→ области, ↑/↓ переключатель окон и запуск (rofi через
  `rofi-toggle`), 4 пальца ↑/↓ развернуть/вернуть (`deskd-ctl`). Двухпальцевый свайп — родной:
  плагин `assets/qt-scroll-phases` восстанавливает фазы прокрутки для Qt 6 на X11
  (`QT_QPA_GENERIC_PLUGINS=scrollphases` в сессии), например перелистывание фото в Telegram.
- **Клавиши**: `~/.config/i3/config`, шпаргалка `Super+/` (`cheatsheet.txt`): `Alt+Tab`,
  `Super+↑/↓/←/→` как в Windows, `Super+R/E/C`, `Ctrl+Shift+Esc` btop, `Super+Shift+S`/`Print`
  скриншоты (`snip`), `Super+Shift+E` меню выключения (то же, что кнопка ⏻ — `power-menu`).
- **Firefox**: `firefox-limited` (мягкий потолок 4 ГБ через systemd) + `firefox-memd`
  (выгрузка до 2 ГБ заранее, `firefox-mem` для настройки на лету). Userscripts и фильтры
  для картинок/YouTube — `assets/browser/` (ставятся вручную в Violentmonkey/uBlock).
- **Избранное** («яблоко» → Favorites, `deskd-favorites`): автозапуск при входе, запуск всех,
  закрепление программ за областями (`~/.config/deskd/apps.conf` → правила `assign` в
  `~/.config/i3/generated/`).

## Решения, которые не стоит пересматривать без причины

- Xfce-инфраструктура + i3, не Plasma и не Wayland: всё недостающее относится к оконному
  менеджеру и стоит один процесс Python; X11 нужен Zoom/OBS и драйверу Wi-Fi.
- picom без blur, `unredir-if-possible`; полноэкранное приложение — настоящее, поверх всего,
  наше «развернуть» — с панелью.
- Без firewall (решение пользователя). LTS-ядро, официальные пакеты, без `-git`.
- Часы `DSEG7 Classic Bold Italic 18` цветом `light`; фон чисто чёрный.
