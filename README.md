# sky-desktop — настройка whitebook

Рабочий стол ноутбука **whitebook** (MacBookPro11,1, Arch Linux, Xorg): инфраструктура Xfce
(панель, xfsettingsd, power manager, Thunar) + оконный менеджер **i3** + свои инструменты,
которые делают из этого законченную среду в духе Windows: шапки окон с кнопками, прилипание
к краям, рабочие области на каждом экране, панель с живыми индикаторами, OSD, календарь,
фон-звёзды. Всё, что установлено в систему, лежит в этом репозитории и ставится одной командой.

Документы: **[ARCHITECTURE.md](ARCHITECTURE.md)** — как устроено и почему ·
**[MAINTENANCE.md](MAINTENANCE.md)** — обслуживание, восстановление, известные хвосты ·
**[CHANGELOG.md](CHANGELOG.md)** — история по раундам · [lab/README.md](lab/README.md) — журнал изменений.

## Структура

```
desktop/                 объявленное состояние системы (источник истины)
  bin/                   → ~/.local/bin        скрипты панели, deskd-ctl, osd, netqd, sky-stars, light-year …
  share/                 → ~/.local/share      deskd/, light-year/, sky-desktop/ (общая библиотека + theme.json), иконки
  config/                → ~/.config           i3, kitty, picom, rofi, touchegg, gtk-3.0, systemd/user, deskd/apps.conf …
  home/                  → ~                   .Xresources
  system/                → /                   /usr/local/bin/xfce-i3-session, /usr/share/xsessions/xfce-i3.desktop
  xfconf/                → xfconf-query        свойства xfconf (раскладка панели), ставятся живьём, откат по свойству
  config/xfce4/panel/    → ~/.config/xfce4/panel   docklike-57.rc: закреплённые в доке (док сам переписывает при перестановке)
tools/desktop.py         check · build · diff · apply · status · packages (файлы дерева и свойства xfconf)
tests/                   unit-тесты календаря и GTK smoke-тест (xvfb)
assets/                  исходники, которые не ставятся как есть: плагин Qt scroll-phases, иконки, userscripts
lab/                     журнал изменений системы (lab, rollback.py, journal.tsv); backups/ вне git
packages.txt             пакеты, которые нужны дереву
```

Файлы дерева — шаблоны: `@HOME@`, `@PROJECT@` и токены стиля из
`desktop/share/sky-desktop/theme.json` подставляются при установке. Бинарные файлы (иконки)
копируются как есть.

## Команды

```bash
make check                 # синтаксис, токены, отсутствие личных путей и цветов-литералов
make status                # чем установленная система отличается от дерева (норма: 0)
make diff                  # то же, но с диффами
make test                  # check + unit-тесты + GTK smoke на Xvfb
make apply EXP=33-name     # test + установка изменённых файлов через lab (журнал под этим именем)
make packages              # каких пакетов из packages.txt нет
make rollback EXP=33-name  # откат эксперимента
```

## Как добавить фикс

1. Правится файл в `desktop/` (никогда — установленная копия в `~`: её перезапишет `apply`).
   Цвета и шрифты — только токенами `@COLOUR_…@` / `THEME[...]`, см. ниже.
2. `make check`, затем `make diff` — видно ровно то, что изменится в системе.
3. `make apply EXP=NN-короткое-имя` — номер следующий по `lab/journal.tsv`.
4. Перезапустить то, что читает файл (таблица в [MAINTENANCE.md](MAINTENANCE.md#что-перезапускать)).
   Проверять на вложенном X (`Xephyr :9` + свой i3) или через `i3-peek`, не на экране пользователя.
5. Абзац в `CHANGELOG.md` (раунд, эксперимент, что и почему), коммит.

Что не описывается деревом — пакеты, удаление файлов, разовые свойства xfconf — идёт через
`lab/lab pkg | undo | remove` с тем же именем эксперимента. Раскладка панели объявлена в
`desktop/xfconf/xfce4-panel.xml` (формат xfconf, личные пути и шрифт — токенами): правки через
настройки панели переносятся в этот файл копией `~/.config/xfce4/xfconf/xfce-perchannel-xml/xfce4-panel.xml`
(`make status` покажет расхождение), `make apply` ставит отличающиеся свойства через `xfconf-query`.

## Система стиля

`desktop/share/sky-desktop/theme.json` — единственное место, где живут цвета и шрифты.

| Ключ | Значение | Где |
|---|---|---|
| `background` `surface` `border` | `#000000` `#12171a` `#1e262c` | фон, кнопки/шапки, рамки |
| `foreground` `text` `muted` `dim` | `#dfe8ee` `#c6d0d9` `#5b6b76` `#3f4a52` | текст UI, текст терминала/полосы областей, подписи, пустые области |
| `accent` `light` | `#0d8ecb` `#48daf9` | структурный акцент (рамки, курсор, rofi) и светящиеся индикаторы (панель, часы, календарь) |
| `warning` `danger` `success` `highlight` | `#febc2e` `#ff5f57` `#28c840` `#ffd166` | состояния; те же три цвета у кнопок в шапке окна |
| `layouts` | EN `#3b7ddd` · RU `#8f5b2e` · UA `#ffd447` | индикатор раскладки и OSD |
| `font` `mono_font` `panel_font` | Inter · JetBrainsMono Nerd Font · Diablo 18 | `panel_font` — шрифт индикаторов панели (кроме часов), тот же в xfconf у genmon-плагинов |

Конфиги и shell пишут `@COLOUR_ACCENT@`, `@RGB_LIGHT@` (для `rgba(@RGB_LIGHT@, 0.2)`),
`@HEX_ACCENT@` (без решётки, touchegg), `@FONT@`, `@MONO_FONT@`, `@PANEL_FONT@`. Python читает `THEME[...]`
из `sky_theme`, CSS внутри Python прогоняется через `sky_theme.css()` с теми же токенами.
`make check` не пропустит цвет темы, написанный литералом.

## Правила (согласованы с пользователем)

1. **Весь интерфейс — на английском**; разговор и документация — на русском.
2. **Сначала готовое решение**, своё — только если готового нет или оно хуже.
3. **Каждое изменение системы — через дерево и журнал** (`make apply`, `lab/lab`). Ключи и токены
   (Google, Zoom) в репозиторий не попадают — они в `~/.config/light-year/`.
4. **Проверять до того, как увидит пользователь**: вложенный X (Xephyr + свой i3), `i3 -C`
   перед reload, `i3-peek` для окон на других областях. Ничего не открывать и не кликать на
   экране пользователя без нужды; панель не перезапускать без причины.
5. **Элементы интерфейса не двигаются при смене состояния**: меняются содержимое и подсветка.
   Место под самое широкое значение резервируется заранее (цифры в ячейках, ширина заголовка,
   шесть недель в календаре, один холст у значка).
6. **Ресурсы**: 8 ГБ и Intel HD 5000. Маленькие инструменты — родные и лёгкие; фоновые службы
   работают от событий; постоянных 60-кадровых анимаций нет. Потолок памяти Firefox (4 ГБ)
   меняет только пользователь.
7. **Ничего неиспользуемого не хранить**: устаревшее удаляется целиком, а не выключается.
   Исключение — инструменты резервного копирования: их оставляют, но не запускают.
8. **Настройки любого нашего интерфейса сохраняются сразу**, без кнопки Save — кроме формы
   события в календаре, где пользователь явно попросил сохранять только по Save.
9. Пользователь утверждает план один раз и ждёт результат, а не вопросов по шагам. Если что-то
   делаться не будет — об этом говорится прямо, без тихой подмены решения.
10. `pkill -f` / `pgrep -f` совпадают с собственной командой и убивают оболочку — искать
    процессы по точному имени или PID.
