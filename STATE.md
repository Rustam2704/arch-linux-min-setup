# Состояние настройки — читать первым

Компактная сводка для новой сессии (21.09.2026, после раунда 9).
Подробности: `CHANGELOG.md` (по дням и раундам) · `REVIEW.md` (устройство и методы проверки) ·
`REQUIREMENTS.md` (что просил пользователь) · `PLAN3.md` (план и статус) ·
`lab/README.md` + `lab/journal.tsv` (каждое изменение и откат).

## Машина
MacBookPro11,1: Arch, ядро LTS, **Xorg**, Xfce-инфраструктура + **i3**, picom, rofi, kitty.
2 ядра, 8 ГБ ОЗУ, экран 2560×1600 при масштабе 1.5× (`Xft.dpi 144`), иногда второй экран
HP 22″ (HDMI-2). Акцент `#0d8ecb`, в панели и календаре — `#48daf9`, фон почти чёрный.

## Правила работы (согласованы с пользователем)
1. **Весь интерфейс — на английском**, разговор и документация проекта — на русском.
2. **Сначала ищем готовое решение**, своё пишем, только если готового нет.
3. **Каждое изменение системы — через `lab/lab`** (`write` / `pkg` / `undo`): нужен точный
   итоговый дифф и возможность выложить набор в open source. Ключи и токены в репозиторий не попадают.
4. **Проверять до того, как пользователь увидит:** вложенный X (Xephyr + свой i3),
   `i3 -C` перед reload, `i3-peek` для окон на других областях. Пользователь часто за
   компьютером — не открывать окна на его экране без нужды.
5. Ресурсы: маленькие инструменты — родные и лёгкие. Потолок памяти Firefox (4 ГБ) меняет
   только пользователь.
6. Осторожно с `pkill -f` / `pgrep -f`: шаблон совпадает с собственной командой и убивает оболочку.
7. Пользователь утверждает план один раз и дальше ждёт результат, а не вопросов по шагам.

## Что важно знать про панель (иначе легко сломать)
- Плагины: `1` меню-яблоко · `57` docklike · `45` области · `52`/`53`/`54` линии ·
  `50`/`51` растяжки · `6` трей (пустой) · `58`/`59` отступы · `40` Telegram · `56` отступ ·
  `41` сеть · `42` CPU/RAM · `43` погода · `44` батарея · `20` звук · `55` раскладка ·
  `8` часы · `21` выключение.
- **Шрифт genmon читается только при старте плагина.** Менять так: `xfce4-panel -q`,
  правка `xfconf`, затем запуск. На живой панели правка молча не применится, а при выходе
  панель ещё и перезапишет её своим значением.
- **Запускать панель только через i3** (`i3-msg 'exec --no-startup-id xfce4-panel'`), иначе
  она унаследует окружение текущего процесса и раздаст его всем запущенным из неё окнам.
- Ширину строки областей меряет сам `deskd` (Pango тем же шрифтом, что и панель) — от этого
  зависят зоны клика и цели перетаскивания. Шрифт он берёт из `xfconf` плагина `45`.
- `Ctrl+клик` по любому элементу панели перехватывает сама XFCE (меню элемента), поэтому
  для «нового окна» используется `Shift+клик`.
- **Тег `<img>` у genmon — отдельной строкой**, не внутри `<txt>`: вложенный он рисуется
  дважды и утаскивает подпись вниз относительно соседних плагинов.
- **Свои значки с именем `*-symbolic`** GTK перекрашивает (`rect,circle,path { fill: … !important }`).
  Цвет держится только на inline-стиле с `!important` у каждой фигуры — так сделан динамик.
- **Картинку genmon показывает примерно в 32 px по высоте**, поэтому рисунок должен занимать
  весь холст: поля внутри SVG съедают размер (значок Wi-Fi рисуется 56×35 без полей).

## Открытые хвосты
1. Автозапуск избранного проверится только следующей перезагрузкой; лог — `~/.cache/deskd-favorites.log`.
2. Подключение/отключение HP вживую не пробовалось (логика и создание панели проверены отдельно).
3. Приложение в Zoom Marketplace всё ещё называется `mini-calendar`.
4. У окон во вкладках (tabbed/stacked) цветных кнопок в шапке нет.
5. Шумоподавление микрофона отложено пользователем (он пользуется средствами Zoom).
6. Правый клик в терминале сейчас не передаётся ни приложению, ни выделению. Пользователь
   спрашивал про альтернативы (вернуть расширение выделения / глушить только в программах,
   которые сами читают мышь / повесить на него меню пути) — решение за ним.
7. Память `deskd`: RSS после первого перетаскивания ~88 МБ, но своей памяти там ~27 МБ,
   остальное — общие страницы шрифтов и библиотек отрисовки. Утечки нет, проверено
   `tracemalloc` и `smaps_rollup` (раунд 8).
