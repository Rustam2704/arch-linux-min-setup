# Состояние настройки — читать первым

Компактная сводка для новой сессии (20.09.2026, раунд 6).
Подробности: `CHANGELOG.md` (по дням) · `REVIEW.md` (устройство и методы проверки) ·
`REQUIREMENTS.md` (что просил пользователь) · `PLAN3.md` (план и статус) ·
`lab/README.md` + `lab/journal.tsv` (каждое изменение и откат).

## Машина
MacBookPro11,1: Arch, ядро LTS, **Xorg**, Xfce-инфраструктура + **i3**, picom, rofi, kitty.
2 ядра, 8 ГБ ОЗУ, экран 2560×1600 при масштабе 1.5× (`Xft.dpi 144`), иногда второй экран
HP 22″ (HDMI-2). Акцент `#0d8ecb`, в панели и календаре — `#48daf9`, фон почти чёрный.

## Правила работы (согласованы с пользователем)
1. **Весь интерфейс — на английском**, разговор и документация проекта — на русском.
2. **Сначала ищем готовое решение**, своё пишем, только если готового нет.
3. **Каждое изменение системы — через `lab/lab`** (`write` / `pkg` / `undo`): нужен точный
   итоговый дифф и возможность выложить набор в open source. Ключи и токены в репозиторий не попадают.
4. **Проверять до того, как пользователь увидит:** вложенный X (Xephyr + свой i3 + `testwin.py`),
   `i3 -C` перед reload, `i3-peek` для окон на других областях, подменённый i3 для логики экранов.
   Пользователь часто за компьютером — не открывать окна на его экране без нужды.
5. Ресурсы: маленькие инструменты — родные и лёгкие (календарь ~42 МБ). Потолок памяти
   Firefox (4 ГБ) меняет только пользователь.
6. Осторожно с `pkill -f` / `pgrep -f`: шаблон совпадает с собственной командой и убивает оболочку.

## Что сделано и работает
| Область | Кратко |
|---|---|
| `deskd` (23 МБ, `~/.local/share/deskd/`) | шапки с цветными кнопками, разворот с видимой панелью и точный возврат (заглушка i3), двойной клик, единый движок перетаскивания (левая — плитки, правая — вытянуть; края экрана, цифры в панели), растягивание за промежутки, области у каждого экрана, панель на монитор, RustDesk passthrough, новые окна браузера рядом с браузером и плавающими |
| Панель XFCE | высота 66, значки 48, шрифт Inter 15; области (широкие, кликабельные), сеть (моментальная задержка и медиана — мельче и приглушённее), CPU/RAM, батарея, погода, Telegram настоящей иконкой (акцент = непрочитанные, свой трей выключен), раскладка EN/RU/UA, «яблоко» → меню XFCE, третий пункт Favorites |
| OSD (`osd-daemon`) | громкость/яркость/раскладка поверх полноэкранного, 90% непрозрачности |
| Клавиатура | `Alt+Tab`, фокус `J K L ;`, `Super+стрелки` как в Windows, `Super+Shift+S`/`Print` — скриншоты (`snip`), раскладки по отпусканию клавиш |
| Терминал kitty | правый клик не вставляет, вставка `Ctrl+V`, выделение копируется в буфер, `Ctrl+C` копирует выделенное (без выделения — прерывание), `Ctrl+ЛКМ` открывает путь, средняя кнопка — меню пути, `Ctrl+Shift+O` — открыть выделенное (`open-path`) |
| Firefox | `firefox-memd`: фоновая выгрузка до 2 ГБ, потолок 4 ГБ не трогаем |
| Календарь `light-year` (~42 МБ) | GTK без браузера: месяц по реальным неделям, подсветка правки, время — поле без стрелки со списком под ним и умным вводом цифр (`345` → `03:45`), длительность сохраняется, мини-календарь на дате, оттенки колонок, свайп по месяцам с предзагрузкой, повторяющиеся события (this / following / all), Zoom |
| Экраны | autorandr запоминает раскладку, `deskd` применяет и сохраняет |

Службы (`systemctl --user`): `deskd`, `osd` (обе запускает i3 — им нужен X), `netqd`,
`firefox-memd`. Вместе ~65 МБ и меньше 1% ядра.

## Открытые хвосты
1. Автозапуск избранного проверится только следующей перезагрузкой; лог — `~/.cache/deskd-favorites.log`.
2. Подключение/отключение HP вживую не пробовалось (логика и создание панели проверены отдельно).
3. Приложение в Zoom Marketplace всё ещё называется `mini-calendar`.
4. У окон во вкладках (tabbed/stacked) цветных кнопок в шапке нет.
5. Шумоподавление микрофона отложено пользователем (он пользуется средствами Zoom).
6. Часы в панели (режим LCD) не масштабируются: плагин рисует цифры высотой 24 px при любой
   высоте панели. Если нужно крупнее — менять тип часов на цифровые со шрифтом (стоит `ttf-dseg`).
7. Правый клик в терминале сейчас не передаётся ни приложению, ни выделению — пользователь
   спросил про альтернативы, решение за ним (варианты в ответе раунда 6).
8. У Telegram выключен свой значок в трее, «When window closed» = Close to taskbar: окно
   остаётся жить, иначе счётчик непрочитанных читать неоткуда.
